Built and tested

  • ✓Unbalanced three-phase AC power flow (OpenDSS), cross-checked against a NumPy reference solver
  • ✓Chance-constrained LP-MPC optimiser with a transparent rule-based and no-coordination baseline for comparison
  • ✓Safety layer that verifies every action: VERIFIED / INFEASIBLE / SOLVER_FAILED, never collapsed into ok/not-ok
  • ✓Causal, conformal-calibrated day-ahead forecasting with a documented accuracy benchmark
  • ✓An auditable override ledger: user requests are queued and applied, never silently acknowledged and ignored
  • ✓Flexibility Envelope: per-step mobilisable-capability estimate, explicitly labelled ESTIMATED
  • ✓Decision Trace: a deterministic, human-readable record of every control step's reasoning
  • ✓A three-arm stress comparison: no coordination, battery-only, and full NEOS control, on identical seeded scenarios

Explicitly not built

  • —Hardware-in-the-loop: nothing here commands real equipment
  • —Multi-agent reinforcement learning
  • —A deployed community hub: the hub is a simulated offline-pledging demo (no phone app, SMS gateway or authentication; session-keyed JSON storage) and not the shared-battery energy hub; the rural kit has no field hardware
  • —Island dynamics, black start, protection coordination, DISCOM settlement
  • —Real feeder data — all demand and weather are synthetic
  • —Structural digital-twin mismatch calibration (one physical parameter is calibrated; structural model error is not)
