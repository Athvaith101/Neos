What this is, plainly

What's real: an unbalanced three-phase power flow (OpenDSS), a chance-constrained optimiser, a safety layer that verifies every action, and an automated test suite (count on the Evidence page) covering the control, safety and forecasting logic.

  • No equipment is commanded — simulation only
  • Weather and demand data are synthetic
  • Hardware-in-the-loop is not built
  • Multi-agent reinforcement learning is not built
